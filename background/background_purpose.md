# 项目背景 (Background) 与 目标 (Purpose)

## 1. 数据来源

本分析基于从小红书爬取的 **100 条高赞笔记**（总计 10.5 万点赞、11.4 万收藏）及 **751 条用户评论**，关键词为"澳门旅游攻略"，覆盖 2023-2025 年间游客的真实体验与反馈。

---

## 2. 项目背景 (Background)

### 2.1 澳门旅游需求旺盛，但信息极度碎片化

在 100 条高赞笔记中，**"攻略"一词出现了 167 次**，"路线"出现了 63 次。Top 10 热门笔记全部为攻略类内容，最高单篇点赞达 **2.1 万**，收藏量高达 **2 万**。这表明游客对系统化的澳门旅游信息有着强烈且持续的需求。

然而，现有信息呈现严重的碎片化特征。通过对 751 条评论进行关键词词频分析，信息困惑类表达出现频率极高：

| 关键词 | 出现次数 | 典型场景 |
|--------|----------|----------|
| 怎么 | 61 次 | "怎么去""怎么回""怎么安排" |
| 去哪 | 14 次 | "去哪玩""去哪里了解" |
| 不会 | 8 次 | "不会规划""不会走" |
| 不知道 | 5 次 | "不知道看什么""不知道背景" |
| 不懂 | 1 次 | "不懂历史""不懂文化" |

**信息困惑类关键词总计出现 93 次**，说明游客在获取、理解和整合澳门旅游信息时存在普遍困难。高赞笔记评论区常见"收藏了""mark"，但缺乏一步到位的智能解决方案。

### 2.2 人流拥挤严重影响游览体验

评论数据显示，人流拥挤类关键词出现频率如下：

| 关键词 | 出现次数 | 场景 |
|--------|----------|------|
| 排队 | 25 次 | 发财车、缆车、景点入口 |
| 人多 | 5 次 | 大三巴、官也街等热门景点 |
| 拥挤 | 2 次 | 节假日、周末高峰 |
| 爆满 | 2 次 | 酒店、餐厅、打卡点 |

**人流拥挤类关键词总计出现 34 次**。典型反馈包括：

> "唉我现在就在澳门，真的挺无聊的"（14赞）  
> "要排队很久吗"  
> "2楼很少人下车其实也很难坐的上"  

大三巴作为最热历史地标（被提及 62 次），同时也是人流最密集的景点。多数攻略仅告知游客"去哪里"，却未告知"什么时候去人少""如何避开高峰"。

### 2.3 老城区文化价值被严重低估

数据分析揭示了显著的**热度不均**：

| 景点类型 | 代表景点 | 提及次数 | 特征 |
|----------|----------|----------|------|
| 赌场综合体 | 美高梅、威尼斯人、巴黎人 | 79-83次 | 高度商业化，信息充足 |
| 核心历史地标 | 大三巴 | 62次 | 过度拥挤，打卡化严重 |
| 美食街区 | 官也街 | 50次 | 商业化程度高 |
| 小众文化区 | 路环 | 39次 | 有潜力但信息不足 |
| 历史街巷 | 疯堂斜巷、恋爱巷、议事亭 | 6-10次 | **严重被忽视** |

与此同时，讲解缺失类关键词的词频分析显示：

| 关键词 | 出现次数 | 含义 |
|--------|----------|------|
| 历史 | 22 次 | 游客对历史背景有求知欲 |
| 文化 | 11 次 | 文化体验需求被提及 |
| 为什么 | 9 次 | "为什么会有这个建筑""为什么不了解" |
| 介绍 | 7 次 | "没有介绍""缺乏说明" |
| 背景 | 6 次 | 希望了解建筑/景点的历史背景 |
| 故事 | 4 次 | 对景点背后的故事感兴趣 |
| 看不懂 | 1 次 | 面对景点但无法理解其价值 |

**讲解缺失类关键词总计出现 60 次**。这反映出**游客知道"澳门有历史"，却不知道"去哪里了解历史"**。

### 2.4 现有导览工具存在明显空白

在 751 条评论中，**没有用户提及使用任何语音导览 App 或小程序**。负面体验的关键词词频统计如下：

| 痛点类别 | 关键词 | 出现次数 | 典型表达 |
|----------|--------|----------|----------|
| **体力消耗** | 累 | 15 次 | "走累了""太累了" |
| | 暴走 | 5 次 | "暴走一天""特种兵暴走" |
| | 体力 | 3 次 | "体力不支""费体力" |
| **无聊失望** | 踩雷 | 7 次 | "踩雷了""避雷" |
| | 坑 | 6 次 | "被坑了""避坑" |
| | 后悔 | 4 次 | "后悔来""后悔没做攻略" |
| | 失望 | 2 次 | "挺失望的""和想象不一样" |
| | 无聊 | 1 次 | "真的挺无聊的" |

此外，路线规划与交通类关键词也反映出工具缺失的困境：

| 类别 | 关键词 | 出现次数 | 说明 |
|------|--------|----------|------|
| **路线规划** | 路线 | 63 次 | 最核心的搜索需求 |
| | 安排 | 27 次 | 时间安排的焦虑 |
| | 赶 | 11 次 | "时间赶""赶行程" |
| | 回头路 | 7 次 | 路线设计不合理 |
| **交通困惑** | 发财车 | 70 次 | 免费交通是关注焦点 |
| | 步行 | 57 次 | 大量步行让人疲惫 |
| | 口岸 | 54 次 | 过关流程和交通困惑 |

游客对景点的理解停留在"拍照打卡"层面，缺乏深度文化解读。

> "为了这18张图我去了一趟澳门" —— 典型打卡式旅游心态

## 3. 项目目标 (Purpose)

基于上述痛点，本项目旨在构建一款 **AI 驱动的澳门旧区智能导览系统**，以微信小程序为载体，实现以下核心目标：

### 3.1 核心目标：旧区位置讲解

当用户走进澳门历史城区（如大三巴周边、议事亭前地、疯堂斜巷等），系统根据用户**实时位置**自动推送：
- **文字讲解**：历史背景、建筑特色、文化故事
- **语音导览**：多语言语音播报，解决"不知道看什么"的问题
- **个性化内容**：根据用户国籍/语言偏好调整讲解深度与侧重点

### 3.2 智能路线规划

结合实时数据与用户偏好，生成最优游览路线：
- **人流规避**：基于口岸、景点实时人流数据，动态推荐"人少时段"
- **兴趣匹配**：根据用户选择的旅游类型（文化/美食/摄影/亲子）定制路线
- **路线优化**：避免走回头路，串联历史景点与特色街巷，减少"暴走"和"累"的体验
- **节庆感知**：自动纳入澳门本地节庆活动（如光影节、烟花汇演），调整路线

### 3.3 用户偏好管理

在注册环节即收集关键信息，为后续个性化服务奠基：
- **语言与国家**：确保讲解内容符合用户文化背景
- **兴趣 Checklist**：了解用户来澳目的（娱乐/文化/历史/美食）
- **旅游类型**：区分个人游、家庭游、商务后休闲等不同场景
- **时长规划**：半日游/一日游/深度游的不同策略

### 3.4 人工调度与数据迭代

竞赛周期内 **不进行实时社交媒体监控**；本节所依据的小红书数据为 **已采集的离线快照**（100 条笔记 + 751 条评论），在系统构建阶段一次性清洗入库，用于路线与讲解的推荐先验：
- **离线热度基线**：基于已有笔记的 POI 提及频次与互动量，生成景点热度 / 小众候选权重
- **痛点与避坑知识**：从 751 条评论抽取排队、体力、讲解缺失等标签，写入 RAG 供 Agent 引用
- **人流预测**（若 API 可接入）：整合口岸、景点人流数据，与静态权重结合做错峰建议
- **内容更新**：以人工审核与用户反馈为主通道，持续优化讲解内容（不依赖持续爬取）

## 4. 差异化价值

| 维度 | 现有方案 | 本项目 |
|------|----------|--------|
| 信息获取 | 碎片化攻略，手动拼凑 | 一站式智能导览，按位置推送 |
| 路线规划 | 固定路线，千篇一律 | 动态调整，基于实时人流与兴趣 |
| 文化讲解 | 人工导游（贵/覆盖少）或零讲解 | AI 语音讲解，覆盖所有历史街巷 |
| 语言支持 | 有限 | 多语言，按用户习惯定制 |
| 人流规避 | 无 | 实时感知，智能避开高峰 |

---

## 5. 总结

澳门每年接待数千万游客，其中大量游客对历史文化有浓厚兴趣，却被困在"信息碎片化""人流拥挤""缺乏讲解"的三重困境中。本项目通过 AI Agent 技术，将**实时位置感知**、**智能语音讲解**与**动态路线规划**相结合，为游客提供真正个性化、深度化、智能化的澳门旧区游览体验。
