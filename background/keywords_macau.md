# MediaCrawler 澳门旅游数据爬取清单（扩展版）

## 使用方式

在 `MediaCrawler` 目录下运行：

```bash
# 小红书示例
python main.py --platform xhs --lt qrcode --type search --keywords "关键词" --max-notes 100

# 抖音示例
python main.py --platform dy --lt qrcode --type search --keywords "关键词" --max-notes 100
```

数据默认保存在 `data/` 目录下，以 Excel/CSV 格式导出。

## 执行建议

1. **优先级**：先跑第一组（痛点）+ 第二组前20个（核心景点），这些数据写 background 最有力
2. **平台选择**：小红书优先（攻略质量高、评论详细），抖音补充（热度数据直观）
3. **数量建议**：核心关键词 100 条，长尾关键词 50-80 条即可
4. **时间管理**：每个关键词约 5-10 分钟，建议分批执行，避免触发平台限流
5. **存储注意**：定期清理 `data/` 目录，或按关键词分子文件夹存放
