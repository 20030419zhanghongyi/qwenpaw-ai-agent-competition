# 人工智能倫理與政策考量

本項目涉及路線推薦、位置提示、相片識別、文化內容生成、語音導覽及個人化記錄。項目堅持「以人為本、最少必要、公開透明、可控可責」的原則，AI 僅提供輔助建議，不會取代用戶判斷、官方資訊或專業導航服務。

## 公平性

- 路線推薦只使用遊覽時間、興趣、體力需求、目前位置等與服務直接相關的資訊，不會根據國籍、語言、消費能力等特徵給予差別待遇，也不會預設向特定群體推薦高消費場所。
- 社交媒體熱度可能放大網紅景點和主流旅客的偏好，因此只會將其作為補充資訊，並與官方資料、訪談調研及本地意見互相核實，避免忽視邊緣街區、小眾文化和無障礙需要。
- 項目會在不同語言、年齡、出行方式和步行能力的測試用戶中，評估路線質素、識別準確率和服務可達性；如發現不同群體之間存在明顯差異，將調整資料、規則或推薦邏輯。

## 透明度

- 明確標示由 AI 生成或調整的路線、講解、翻譯、語音和圖片，並說明路線採用「預設路線庫 + AI 微調」方式，而非完全由模型自由生成。
- 向用戶展示影響推薦的主要因素，例如時間、興趣、體力、天氣和人流資訊，並標示外部資訊的更新時間。相片識別的可信度不足時，系統會說明「未能確定」，並提供人工選擇或重新拍攝的選項。
- 文化講解會區分官方史料、學術記載、民間傳說和 AI 生成的情境復原；生成式歷史圖片須標示為示意內容，不會當作真實史料使用。

## 問責制

- 項目團隊對產品中的資料處理、推薦結果和生成內容承擔責任，不會將錯誤歸咎於 Qwen、外部 API 或用戶。團隊會指定負責人處理內容更正、私隱要求、安全事故和用戶投訴。
- 保存必要的資料來源、模型及提示詞版本、工具調用和關鍵推薦記錄，以便追查問題；系統日誌會進行去識別化處理並限制存取，不會記錄無關的完整對話、相片或精確行蹤。
- 高風險內容上線前會由團隊或本地文化顧問審核。如發現錯誤路線、失實講解、歧視性結果或資料外洩，團隊會及時停用相關功能、通知受影響用戶並完成修正。

## 私隱

- 實施預設私隱保護和資料最小化。定位、相片、歷史足跡、收藏和意見回饋會按功能分別取得清晰授權，預設不會持續追蹤，也不會因用戶拒絕非必要授權而阻止其使用基本導覽功能。
- 精確位置只會在導航或位置提示期間使用，用戶可隨時暫停；上載相片前會提醒用戶避免拍攝無關途人、住宅內部和敏感資訊，必要時對人臉、車牌及相片元資料進行模糊化處理或移除。
- 資料會採用加密傳輸、受控儲存和最短必要保存期限。用戶可查閱、更正、匯出或刪除個人資料；未經另行明確同意，用戶相片、行蹤和對話不得用於模型訓練、廣告分析、用戶側寫或向第三方提供。
- 使用雲端模型、地圖及語音服務前，團隊會審查其資料處理地點、保留規則和安全能力。涉及未成年人、跨境傳輸或其他敏感資料時，將採取更嚴格的授權和保護措施。

## 安全與可靠性

- 路線會優先從經人工審核的路線庫中選擇，並核實開放時間、道路可達性、天氣和人流資訊。系統不會推薦危險、封閉或明顯不適合用戶體力狀況的路段；如資訊不足，將採用較保守的方案。
- AI 導覽不會作為緊急救援、交通管制或絕對準確的導航依據。介面會提醒用戶留意現場標示和官方通知，並提供官方地圖、天氣及緊急服務入口。
- 對上載檔案、外部工具和 Agent 調用實施格式驗證、權限控制、密鑰保護、調用頻率限制和異常監測，防範惡意檔案、提示詞注入、越權存取及第三方服務故障。可信度不足的內容不會被表述為確定事實。

## 人類控制

- 用戶擁有最終決定權，可查看推薦依據，自行新增、刪除或調整節點，亦可跳過講解、關閉語音和定位、撤回授權及刪除歷史記錄。
- 位置提示和語音播放須由用戶主動開啟或確認，不會採用誘導授權、預設勾選或難以退出的設計。明信片打卡只用於鼓勵探索，不會透過獎勵機制迫使用戶前往不安全或不願到訪的地點。
- 系統會避免一味迎合用戶或編造史料；當用戶的假設與可靠資料有衝突時，系統應指出差異並提供資料來源，而非以「提高滿意度」為由附和。

## 政策遵循與持續管治

項目將根據服務對象和資料流向，遵守適用的個人資料、網絡安全、知識產權及生成式人工智能規定，包括澳門《個人資料保護法》；如服務和資料處理適用中國內地法律，則同時落實《個人信息保護法》和《生成式人工智能服務管理暫行辦法》等要求。文化資料、社交媒體內容及生成的明信片將確認來源和使用權限，避免未經授權複製或作出誤導性再現。
