# V4 手机竖屏前端与交互冻结规范

## 1. 设备与方向

- 首要设备：手机浏览器。
- 默认方向：竖屏。
- 核心验收宽度：360px、375px、390px、412px、430px。
- 桌面端只做居中预览，不重新设计成桌面双栏产品。
- 桌面容器最大宽度建议 `480px`，两侧显示中性背景。
- 使用动态视口高度 `100dvh`，避免浏览器地址栏导致底部按钮被遮挡。
- 所有主要按钮必须处于单手可触达的底部区域。

## 2. 页面动线

1. 偏好页故事海报入口；
2. 故事封面；
3. 开场漫画与道具发现；
4. 六站路线纵向地图；
5. 当前章节到达确认；
6. 到达漫画；
7. 玩家与阿莲对话；
8. 现场观察与知识卡；
9. 谜题；
10. 花瓣奖励；
11. 下一站提示；
12. 大炮台结局与今日补记。

## 3. 页面布局

### 3.1 故事封面

- 单列；
- 上部 60% 为 9:16 海报裁切区；
- 下部为标题、简介、时长、六站和“开始故事”；
- 按钮固定在底部安全区上方；
- 已有进度时按钮文案改为“继续故事”。

### 3.2 路线页

- 使用纵向时间线，不使用横向大地图作为唯一导航；
- 每站显示地点、预计时间和状态；
- 只允许打开当前站与已经完成的站；
- 当前站突出显示；
- 地图图片是补充，可点击全屏查看并缩放。

### 3.3 章节页

章节页固定顺序：

1. 地点与章节标题；
2. 到达漫画；
3. 对话；
4. “现场观察”任务；
5. 局部双图或纸条；
6. 谜题；
7. 提示与跳过；
8. 结果说明；
9. 花瓣奖励；
10. 下一站。

不得把所有信息挤在同一屏；使用自然纵向滚动。

### 3.4 对话

- 一次显示一句，用户点击“继续”进入下一句；
- 当前说话人立绘靠近对应气泡；
- 玩家用右侧气泡，不使用固定人物贴图；
- 阿莲用左侧气泡和固定立绘；
- 阿澜、M先生只在阅读纸条或回忆时出现；
- 不允许同时堆叠十几条聊天记录；
- 可提供“查看本段全文”，但默认保持节奏。

### 3.5 谜题

- 谜题交互控件必须由前端绘制，不把可点击选项烘焙进图片；
- 提交按钮固定在当前谜题卡底部；
- “查看提示”和“跳过本关”使用次级按钮；
- 跳过前显示确认说明：“仍可继续故事，本关会记录为已跳过”；
- 错误答案不清空用户已选内容；
- 所有图片谜题支持双指缩放或全屏查看。

### 3.6 阿莲 Agent

- 每个地点提供浮动入口“问阿莲”；
- 打开后使用底部抽屉，不覆盖整个章节上下文；
- 默认给出 3 个与当前地点有关的建议问题；
- 回答需显示内容类型或来源标签；
- Agent 不直接说出当前谜题答案；
- 网络或 Agent 不可用时，仍显示故事 JSON 中的预置知识卡。

## 4. 触控与可访问性

- 点击目标最小 44×44 CSS px；
- 正文不小于 16px；
- 主要按钮文字不小于 16px；
- 行高不低于 1.5；
- 不以颜色作为唯一状态提示；
- 图片必须有替代文本；
- 漫画字幕、对话和谜题正文全部使用 HTML 文本；
- 支持系统字体放大；
- 动效应尊重 `prefers-reduced-motion`。

## 5. 竖屏素材显示

| 素材类型 | 首选比例 | 页面用法 |
|---|---:|---|
| 故事封面 | 9:16 | 封面上半部 |
| 到达场景 | 3:4 | 章节首图 |
| 漫画分镜 | 4:5 | 纵向逐格阅读 |
| 线索/纸条 | 4:5 | 可放大卡片 |
| 地图/平面图 | 4:5 | 可缩放查看器 |
| NPC 立绘 | 2:3 透明图 | 对话侧边或底部 |
| 奖励花瓣 | 1:1 透明图 | 奖励弹层 |
| 最终重合图 | 4:5 | 结局主图 |

横向原图允许作为素材来源，但进入网页前必须制作竖屏安全裁切版本。

## 6. 图片缺失与失败降级

- 每个 `asset_id` 都有固定占位框；
- 图片未交付时显示章节名、素材类型和简洁线稿占位；
- 加载失败不得阻断对话、谜题或按钮；
- 不得因为等待生图而把文字内容临时写死进组件；
- 最终替换图片时只增加文件，不改接口和页面结构。

## 7. 前端状态边界

前端可以保存：

- 当前漫画阅读到第几格；
- 当前对话阅读到第几句；
- 当前谜题未提交的临时选择；
- 图片查看器缩放状态。

前端不得自行保存为最终真相：

- 是否到达；
- 是否通关；
- 是否跳过；
- 已获得花瓣；
- 当前节点；
- 故事是否完成。

这些状态必须以故事会话接口返回值为准。

## 8. 移动端验收

- 360×800 下无横向滚动；
- 390×844 下底部按钮不被浏览器工具栏遮挡；
- 430×932 下图片不拉伸；
- 旋转为横屏后给出“建议竖屏体验”，但不强制锁死；
- 慢网下先显示文字和占位；
- 刷新页面后从后端恢复当前节点；
- 返回上一页不会重复提交动作；
- 跳过、重试、提示和完成结局均可单手操作。
