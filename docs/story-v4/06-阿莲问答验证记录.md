# 问阿莲：Guide 复用修复与验证

验证日期：2026-08-31。工作分支：`chensirui`；修改前基线：`153b87f`。

## 1. 结论与原因

三条线路继续使用 QwenPaw 的同一个 `guide` Agent 和 `macau-guide` Skill。
问阿莲验证期间没有新建独立的阿莲 Agent，也没有修改当时运行中的 QwenPaw Agent/Skill 配置。

旧面板把章节目标、事实和虚构说明拼进 `question`，整体截断到 1000 字符后发送。
后端普通 `/guide/ask` 默认走快速本地资料及联网摘录，不一定调用 Guide 生成回答。
因此剧情文字进入了搜索问题，却没有成为 Guide 可以使用的独立剧情资料；序章道具又经常
不对应真实 POI。旧面板还没有传入多轮历史、角色和禁止剧透边界。

真实基线中，莲城的“这本古书是什么？”和路环的线路比较返回 `source=empty`；
氹仔的“这些信是真的吗？”返回了与问题不相符的博物馆网页摘录。普通妈阁庙 Guide
仍能给出地点摘录。这些现象由调用路径和上下文丢失解释，不是通过重新灌入 RAG 数据修复的。

## 2. 修改后的行为

- 前端分别发送原始问题、`story_context={session_id, chapter_id?}` 和最近 8 条问答历史。
  不再用章节说明挤占问题长度。关闭再打开面板保留本章对话，切换会话、章节或语言隔离历史。
- 后端复用现有故事会话的所有者、版本和解锁校验，读取指定已解锁章节的公开内容。
  使用真实 POI ID（存在时）取得 Guide 资料；场景、对话、知识卡、事实与虚构边界独立注入。
- 故事请求自动进入同一个 `guide_agent.answer`，不用额外设置 `enhance=true`。
  即使没有 POI 或联网资料，也可以依据剧情回答。各线路的公开封面简介支持主题比较。
- 不把谜题对象、正确答案、奖励状态、未解锁场景或玩家私人补记放入隐含上下文。
  只有真实完成的会话才带入已公开结局。历史不能证明玩家已经通关，也不作为事实依据。
- 保留 Guide 的多语言处理、资料来源和 Reviewer 流程；允许针对具体未知细节说明不确定，
  或温和拒绝剧透，不再把这类合理回答统一替换成“换个问法”。
- 格式错误、语言不符或缺乏本轮依据的新年份，合计最多重新生成一次；单次受配置中的
  QwenPaw 超时约束。年份检查只覆盖 1000–2099 的四位数字，不是通用史实校验。
- 无法取得合格回答时显示本章预置资料，并说明它不是刚才问题的新回答。
  前端分别标注“阿莲 AI 问答”“AI + 公开资料”“本章预置资料”，修复原来误标 Web 的逻辑。

请求与响应详情见 [接口契约 4.3](01-后端接口与故事数据契约.md#43-agent-上下文)。

## 3. 真实服务验证

使用本地后端 `8001`、前端 `5173` 和 QwenPaw `8088`，没有用 mock 代替这些端到端调用。
本轮发现的 Guide 活跃模型为 `dashscope/glm-5`。后端已只重建 `backend` 容器以加载修复；
没有重置数据库、重新 seed、修改 QwenPaw 配置或触发图片/TTS 生成。

验证通过单独创建的 `Alian QA` 测试账号进行，只推进了该账号的测试会话。
氹仔完成页使用测试会话跳过章节后选择结局；这不代表人工解出了所有谜题。
凭据文件留在系统临时目录，不放入代码、报告或问答证据中。

| 场景 | 观察结果 |
| --- | --- |
| 莲城序章：古书是什么 | 实际 Guide 回答书的背景，区分真实志书与游戏中的信封、夹图 |
| 氹仔序章：这些信是真的吗 | 实际 Guide 区分虚构信件和真实地点，不再返回无关博物馆摘录 |
| 路环序章：与莲城有什么不同 | 依据公开简介比较海边生活记忆与城市沿革；最终复测未重现错误地图年份 |
| 三线第一站的文化问题 | Guide 可使用地点/剧情资料回答；路环最终使用“天后古庙与观音古庙”准确题名复测 |
| 氹仔连续追问 | 显式传入上一轮问答后，能够承接“它”和“这封信”等指代 |
| 三线索要谜底、假称已通关 | 测试回答均拒绝直接列出完整答案，转为观察或页面提示引导 |
| 英文、葡语、繁体中文 | 英文 API、葡语最终 API，以及繁体中文真实界面均取得 Agent 回答 |
| 氹仔真实完成状态 | 可讨论未来信的收束；一次请求超时降级，随后同题重试和完成页界面问答成功 |
| 普通 Guide `enhance=true` | 最终复测取得 `source=agent+web`，未携带故事上下文 |

验证中修正了两个模型输出问题：路环曾返回非 JSON 的工作总结；随后一次线路比较又添加
了资料未支持的地图年份。增加有限重试、公开简介和证据约束后，相关样例复测成功。
原始失败记录仍保留，不将中间输出当作修复后的成功证据。

最终 API 抽测 5 项中，4 项返回 Agent 回答，1 项返回诚实的预置资料降级。
该降级的后端日志为 `POST /api/console/chat exceeded 60.0s total duration`；
同题再次请求用时 49.22 秒，返回 `agent+story`。因此不保证模型每次都能及时完成。
故事样例多数约 40–64 秒；检索、模型、Reviewer 和重试都会影响总耗时。

部分原始结果的 Reviewer 为 `revise`，并非全部 `pass`。本记录证明调用、剧情上下文、
交互和降级行为，不代表所有生成内容已通过全面史实或伦理审查；本次没有改造 Reviewer。
