# Macau StoryWalk — 前端設計計劃（Design Plan）

> 設計負責人視角的視覺方向書。不是工程任務清單（那在 `frontend/FRONTEND_PLAN.md`），
> 而是回答一個問題：**這個產品看上去憑什麼不像任何一個別人的旅遊 App？**
> 內容全部基於 `plan/report ver4.5.docx`，不虛構景點、不編造數據。
>
> **實現狀態（2026-07）：** Web MVP 已按 Lovable 設計包落地為 **Morandi 紙色 + sage 綠** 色板
> （見 `src/index.css`）。下文 §3 深底 / ochre 方案保留為早期探索記錄，不以之為當前實現準則。

---

## 0. 一句話立場

> **「踩住故事行。」** 把澳門舊區腳下那片葡式碎石路（calçada）變成會說話的介面——
> 你走過的每一段路，都是一句被解鎖的旁白。

這是給評委的 Hero 論點：這不是又一個「景點列表 + 地圖 + 路線」的攻略工具，而是一個**在你真正走進舊區那一刻才開口**的伴行敘事者。

---

## 1. 主語（Subject）／觀眾（Audience）／頁面唯一的任務

- **主語**：澳門舊區的「可行走的城市故事」——議事亭前地、瘋堂斜巷、戀愛巷、望德堂區、福隆新街、下環區這些**真正有歷史但被攻略忽略**的街巷。
- **觀眾**：澳門自由行旅客——半日 / 一日、親子或獨行、想拍又怕累、想懂歷史但不想自己做功課的人。
- **頁面唯一的任務**：讓評委在 **5 秒內**理解「這是一個會在對的地點、對的時機講對的故事的導覽夥伴」，而不是一個景點大全。

設計的每一個選擇，都從這三條推導出來。

---

## 2. 設計概念：鋪路作為敘事者（Pavement as Narrator）

澳門舊區最被低估、卻最無可取代的視覺資產，是腳下那片**黑白葡式碎石路**——
它的波浪紋（calçada portuguesa）本身就在講故事：象徵葡萄牙人橫越大洋而來（報告第五章「瘋堂斜巷」講解原話）。

所以把這條紋路做成整個介面的**結構線**：

- 頁面像一段段相連的「路面」，段落之間用碎石波浪紋做分隔（不是裝飾線，是「路接著路」的語意）。
- 講解卡片像一塊塊**從路面裡被托起的石碑（plaque）**——對應「位置觸發，地點開口」。
- 雙語眉題（PT · 中文）做結構標記，因為澳門街牌本來就是雙語並置——這是資訊，不是裝飾。

### 簽名元素（Signature）——只能有一個

> **「會說話的碎石」**：Hero 區用 SVG 畫出葡式波浪紋路面，一張「叮」的瘋堂斜巷講解石碑靜靜壓在路面上；
> 向下滾動時，每張位置觸發卡片像石碑被托起浮現，右上角一枚 azulejo 鈷藍小角、一枚 oxblood「叮」觸發點。

把所有張力都花在這一處。其餘一切安靜、克制、服從它。

## 3. Token 系統

### 3.1 色彩（Palette）—— 6 個命名色，全部有出處

| Token | Hex | 來歷（subject's own world） | 用途 |
|---|---|---|---|
| `--ink` | `#17120D` | **碎石玄武岩**（calçada basalt），暖近黑 | 頁面地、主文字（深底） |
| `--limestone` | `#ECE3D0` | **石灰砂漿／老化紙**（石與石之間的暖白） | 淺色石碑、深底上的文字 |
| `--ochre` | `#D98B2E` | **望德堂牆面的洗水蛋黃** | **主品牌色**（logo、強調、連結） |
| `--azulejo` | `#2E6CA4` | **葡式花磚鈷藍**（azulejo underglaze） | 次強調、結構標記、資料 |
| `--oxblood` | `#B23A2B` | **屋頂瓦／老招牌朱紅** | **僅用於「叮」位置觸發那一刻** |
| `--jade` | `#5C8C7A` | **銅綠／石上青苔** | 正向狀態、資料輔助 |

輔助階調：`--ink-2 #241C15`（深底卡片抬升面）、`--limestone-dim #C9BEA8`（次級文字）。

**為什麼是深底，而不是旅遊站常見的米白？**
這是本次承擔的真實美學風險（見 §7）。理由：產品不是旅遊手冊，而是**黃昏走街時的伴行敘事者**；深底讓望德堂的蛋黃、花磚的鈷藍、招牌的朱紅像澳門藍調時刻那樣**自帶光地浮起來**，也讓唯一的 oxblood「叮」真的像一記打斷。同時它直接鏡像了身體經驗——腳下是涼而暗的石板，抬頭是暖而亮的立面。

### 3.2 字體（Type）—— 三種角色，各一張臉

| 角色 | 拉丁 | 中文 | 為什麼選它 |
|---|---|---|---|
| **Display 石碑之聲** | `Fraunces` | `LXGW WenKai 霞鶩文楷` | Fraunces 帶可變光學尺寸與柔軟個性；霞鶩文楷是帶手寫溫度的楷書——呼應澳門**手繪招牌**，是記憶點。 |
| **Body 故事之聲** | `Newsreader` | `Noto Serif SC` | 安靜可讀的襯線——這是講故事的 App，正文用襯線強化「有人在對你說」，而非「你在查資料庫」。 |
| **UI 控制之聲** | `Inter` | `Noto Sans SC` | 中性、給籌碼／標籤／導航用——讓控制項不搶戲。 |

**型級（Type scale）**：`--d-1`(clamp 2.4→4.2rem) · `--d-2`(1.6→2.4rem) · `--lead`(1.15→1.35rem) · `--body`(1rem) · `--ui`(0.8rem, letter-spacing .08em, uppercase 用於眉題)。行高正文 1.7、標題 1.1，中文比拉丁略鬆。

### 3.3 佈局（Layout）

- **行動優先單欄「路面」**：`max-width ≈ 720px`，居中於玄武岩地。寬屏時石碑可並排，但敘事流永遠是單線（走路本來就是一條線）。
- **段落 = 路面 stretch**：每段以雙語眉題起頭（如 `O PROBLEMA · 痛點`），以碎石波浪分隔線收尾。
- **石碑（plaque）**：淺色 `--limestone` 卡片、圓角 6px（不是 0，也不是 24）、細微投影、左上一道 3px ochre / azulejo 色條標明類別。
- **結構性編號**只在「核心流程」一段出現（語言→偏好→路線→導覽→明信片）——因為它**真的是一個序列**，順序承載資訊。其餘段落不用 01/02/03（避免無意義裝飾編號）。

### 3.4 動效（Motion）—— 克制，只編排一個時刻

- 載入時 Hero 的波浪紋用 `stroke-dashoffset` 像被「鋪出來」一樣畫過去（一次）。
- 滾動時石碑 `opacity/translateY` 淡入浮起（IntersectionObserver）。
- **全程 `prefere-reduced-motion` 下關閉**，並保證可見鍵盤焦點、行動斷點。
- 不做散落的 hover 閃爍——多餘動效是 AI 味的主要來源之一。

## 5. 文案原則（符合報告語氣）

- **粵語／繁體為主**——匹配報告與澳門語境；眉題用葡語＋中文並置（街牌邏輯）。
- 寫使用者的視角：是「幫你少走回頭路」，不是「基於多 Agent 路線優化引擎」。
- 觸發用語承襲報告的「叮～你已經行近…」——這是產品的聲音簽名，別稀釋。
- 按鈕寫動作後果：「生成我的路線」而非「提交」。

## 6. 與現有 React 工程的關係

| 本設計交付 | 對接 `frontend/` 工程 |
|---|---|
| `index.html`（概念頁） | 證明視覺系統成立；**不替換** `frontend/index.html`（Vite 入口） |
| Token（§3） | 直接搬進 `frontend/src/index.css` 的 `:root`，取代現有 `--primary/--accent` |
| 石碑／籌碼／眉題組件 | 對應 `FRONTEND_PLAN.md` 的 `RouteSummaryCard / ReasonChips / PoiGuideCard` |
| 路線卡／調整 diff／觸發 toast | 對應 `RouteResultPage / AdjustmentDiffCard / TriggerToast` |
| 雙語眉題系統 | 接 `i18n.ts` 的 zh-CN/zh-TW/en/pt 四語字典 |

**移植第一步**：先把 `:root` token 與字體棧換過去，現有 React 頁面會立刻獲得本設計的底色與字氣，再逐頁替換組件樣式。

## 7. 自我批判（Self-critique）

- **深底會不會像 AI 預設 #2（近黑 + 酸性單色）？** 不會——我用的是**暖玄武岩**而非冷鋅黑，且不是單一酸性強調色，而是**從澳門真實立面抽出的層次粉彩**（蛋黃＋鈷藍＋朱紅＋青苔）。波浪碎石是專屬母題。
- **雙語眉題＋襯線會不會 drift 成預設 #3（報紙版 hairline）？** 不會——我做的是**柔軟石碑、暖深地、波浪分隔**，不是零圓角密排專欄。雙語是結構（真實街牌），不是裝飾版式。
- **暖白 `limestone` 會不會變成預設 #1（#F4F1EA 米白）？** 不會——它只作**石碑表面**局部出現，頁面地是玄武岩，不是米白鋪滿。
- **風險本身**：旅遊產品用深底是反直覺的。辯護見 §3.1——這正是「踩住故事行」的夜走氣質，且讓唯一的「叮」具備打斷力。**不冒這個險，反而是更大的風險（又一個米白旅遊站）。**
