## 0. 文档说明 / 怎么用这份计划

- 这是一份**执行级**计划：每个阶段都有「交付物」「验收标准」「可勾选 checklist」「责任人」。
- 推进顺序 = 严格按阶段（Phase 1 → 6），但**相邻阶段可重叠 1 周**（见 §3 甘特图）。
- 任何无法在初赛（8/9）前完成的功能，**降级到复赛阶段**（Phase 5/6），不要拖慢核心闭环。
- 术语：**核心闭环** = 注册/语言选择 → 偏好输入 → 预设路线配对 + AI 微调 → 地图与行程卡片展示 → 位置触发讲解 → 打卡/明信片。这是初赛 Demo 的最低红线。

### 当前实现总原则（2026/07/01 更新）

- 路线能力采用 **「预设路线模板 + POI 标签/向量召回 + 规则约束 + Agent 微调」** 的混合架构，不走“纯规则”也不走“纯大模型自由生成”。
- **预设路线库继续保留**：它是冷启动兜底、高质量模板与 Agent few-shot 样本来源，不在初赛阶段废弃。
- **向量库优先服务 POI 层，不先服务整条路线层**：先做“找相似景点 / 找主题候选点”，再由路线规划器决定这些点能否拼成可走的路线。
- 路线生成必须受硬约束控制：**总时长、步行距离、区域连续性、避免回头路、体力强度、亲子/摄影/美食等显式偏好**。
- QwenPaw Agent 在初赛阶段主要负责三件事：**需求结构化、路线微调、文化讲解**；不要求每次从零生成完整 itinerary。

## 4. 第 0 周必做的技术决策（W1 内锁定，写进 `docs/meeting-notes.md`）

> 这些决策卡住后续所有开发，**W1 结束前必须定**。下面给出推荐默认值，团队确认即可。

| 决策项 | 推荐默认 | 理由 |
|--------|----------|------|
| Web 前端框架 | **React + Vite + TS**（或 Next.js） | 生态成熟、地图/TTS 组件多、后续可改 Taro 迁小程序 |
| 小程序框架（复赛） | **Taro 4（React 语法）** | 与 Web React 代码最大化复用 |
| 后端 | **Python FastAPI** | 与 RAG/数据 Python 栈一致，Qwen SDK 友好 |
| Agent 平台 | **QwenPaw**（百炼）+ Qwen API | 赛题指定 |
| 向量库 | **pgvector**（Postgres 扩展） | 轻量、单机即可、运维简单；规模大再换 Milvus |
| Embedding | **DashScope text-embedding-v3** | 与 Qwen 生态一致 |
| 地图 SDK | **高德 Web API**（国内）+ 澳门 POI 兼容 | 免费 quota 够 Demo |
| TTS / 语音 | **CosyVoice / Qwen-TTS**（支持粤语/葡语） | 多语言讲解刚需 |
| 数据库 | **PostgreSQL**（用户/路线/打卡） | 单一存储含 pgvector |
| 部署 | 阿里云（百炼代金券） | 与 QwenPaw 一致 |

**补充实现决策（建议直接采用）**

- 路线规划主链路：`Route template retrieval -> Candidate POI recall -> Constraint-based routing -> Agent adjustment`
- 候选 POI 召回来源：`theme/suitable_for 标签 + 离线热度权重 + 向量相似度 + 可选实时约束`
- 向量化对象：**POI 统一描述文本**（名称 / 区域 / theme / suitable_for / intro / history / architecture / story / observation_tips）
- 路线引擎优先级：**先可解释、可兜底，再追求生成感**

## 6. 分阶段计划与 Checklist

### 🟦 Phase 1 — 需求整理与资料准备（W1：07/01–07/07）

**目标**：建一个能支撑原型测试的**最小数据集 + 可计算 POI 层**：30 个 POI + ≥6 条预设路线 + XHS 数据入库 + 路线生成所需标签字段。不追求一次收齐全部澳门资料。

**交付物**：`data/pois.json`、`data/routes.json`、RAG 可检索、XHS 权重表、POI 扩展标签 schema。

**验收**：随便给一个 POI 名（如"疯堂斜巷"），RAG 能检索出 ≥1 段讲解；随便给一组偏好，能从 `routes.json` 配对出 1 条路线；随机给一个 POI，能找到至少 2 个可解释的相似/可替换候选点。

**Checklist**
- [ ] 锁定 §4 技术栈决策，写进 `docs/meeting-notes.md`
- [ ] 确定首批 **6 个重点旧区**（建议：议事亭前地 / 疯堂斜巷 / 恋爱巷 / 望德堂区 / 福隆新街 / 下环区）
- [ ] 整理 **30 个文化节点 POI**，每条含：名称/坐标/街区/主题/基本介绍/历史背景/建筑特色/文化故事/建议观察角度/适合人群/来源类型
- [ ] 设计 **POI 数据 schema**（JSON），并导出 `data/pois.json`
- [ ] 在 POI schema 中补充**可计算标签字段**：`visit_duration_min`、`best_time`、`indoor_outdoor`、`crowd_level_base`、`photo_score`、`food_score`、`history_score`、`family_score`、`night_score`、`walkability_score`、`region_cluster`、`nearby_poi_ids`
- [ ] 统一 `theme / suitable_for / physical / duration` 词表，确保 Route / POI / 用户偏好 / Agent 输出完全兼容
- [ ] 编写 **≥6 条预设路线**，每条含：路线名/主题/起终点/节点顺序/预计用时/建议停留/适合人群/可替换节点
- [ ] 设计路线 schema，导出 `data/routes.json`（半日文化/一日探索/摄影打卡/美食/亲子轻松/低步行强度）；每条路线都应明确自己是**模板路线**而非唯一答案
- [ ] `scripts/clean_xhs.py`：清洗 100 笔记 + 751 评论 → 抽取 POI 提及频次 / 痛点标签（排队·累·不懂历史）/ 避坑表达
- [ ] 生成 **预计算权重表**（POI 热度、拥挤关联、小众候选）→ 写入 `data/weights.json`
- [ ] 设计 `weights.json` 扩展字段：除 `poi_heat` 外，预留 `crowd_risk`、`pain_point_tags`、`alt_poi_candidates`、`theme_bias`
- [ ] `rag/ingest.py`：把 POI 讲解 + 典型游客困惑表述 chunk 化、embedding 入 pgvector
- [ ] 为每个 POI 生成**统一向量化文本**，作为后续相似景点召回与主题召回的 embedding 输入
- [ ] `rag/retrieve.py`：实现 `retrieve(query, k)` 接口，本地跑通检索
- [ ] 规划 `poi_embeddings` / `poi_chunks` 表结构：讲解检索与路线候选召回可共用同一个 pgvector 实例
- [ ] 来源分级标签入库（官方史料 / 学术 / 民间传说 / AI 整合）—— 落实伦理透明度
- [ ] **M1 自检**：随机抽 5 个 POI 检索，结果相关性人工打分 ≥4/5

### 🟨 Phase 3 — 整合 QwenPaw Agent 与路线微调（W3–W4：07/15–07/30）

**目标**：把"固定路线推荐"升级为"模板路线 + 候选 POI 召回 + AI 微调"。本期只做 **3 个核心 Agent**：需求理解 / 路线配对与微调 / 文化讲解。

**交付物**：Agent 接入 QwenPaw，能响应自然语言调整路线（"不想太累""加个拍照点"）并生成讲解。

**验收**：复现设计书 §5 对话示例——用户说"半天+拍照+不想太累"，系统能从路线模板中配对并微调（换点/加休息点/调顺序），并给出理由；若要换点，必须优先从**相似 POI 候选池**中选择。

**Checklist**
- [ ] QwenPaw 平台账号 / API Key / 环境打通，跑通 hello-agent —— ✅ P0 连接基座已就位（`qwenpaw_client.py` + `/agents/ping` 静态验证 reachable/版本/agent）；"hello-agent" 真实调用待 P1 route agent 建好后端到端验证

### 🟧 Phase 4 — 地图 / 位置提醒 / 拍照识别 / 语音导览（W4–W5：07/22–08/06）

**目标**：让系统从"出发前规划工具"变成"行走中的导览伙伴"。拍照识别若来不及，可降级到复赛。

**交付物**：位置触发讲解 + 语音播放（必做）；拍照识别讲解（尽量做）；多语讲解版本。

**验收**：模拟进入"疯堂斜巷"围栏 → 自动/确认后推送讲解并能播放语音（普通话+粤语至少各一）。

**Checklist**
- [ ] 地图 SDK 深度接入：步行路径 polyline、预计步行时间、距离计算
- [ ] **地理围栏 / 位置触发**服务：coarse GPS → 判断是否进入 POI 缓冲区 → 触发
- [ ] `POST /api/v1/guide/trigger`（lat,lng → 推荐讲解）
- [ ] 前端位置上报 + 触发提醒弹层（"叮～你已靠近 XX，要听讲解吗？"）
- [ ] 用户**主动确认后播放**（不做持续陪伴式语音对话，控制难度与成本）
- [ ] **TTS 接入**：讲解文本 → 音频 URL（CosyVoice/Qwen-TTS）
- [ ] 粤语讲解版本生成（澳门本地导览口吻，非生硬直译）
- [ ] 英文/葡文讲解版本生成（避免直译，按国际游客表达）
- [ ] 多语 Agent（设计书中的"多语言生成 Agent"）封装
- [ ] **拍照识别**：`POST /api/v1/guide/photo` 上传图 → 图像理解 + 定位 + 知识库 → 讲解
  - [ ] 接 Qwen-VL 多模态识别建筑/花砖/招牌
  - [ ] 识别置信度不足时回"未能确定"+ 提供人工选择/重拍
- [ ] **多模态内容**（可选）：历史场景插画 / 视觉讲解卡片（静态图优先，视频留复赛）
- [ ] **私隐**：上传照片先经 `scripts/scrub_image.py` 脱敏（剥离 EXIF + 人脸/车牌模糊）；上传前提示避免拍到途人/住宅/敏感信息
- [ ] **人类控制**：位置触发"先问后播"，不自动连播；定位/相册/通知分别授权 + "暂停定位"；关定位仍可基本导览（降级）
- [ ] **安全**：导览页固定安全免责 + 官方地图/天气/紧急电话入口；AI 不作紧急/绝对导航依据
- [ ] **M4 自检**：户外实地走 1 条路线，位置触发成功率与语音体验记录

## 11. 伦理落地（基于 QwenPaw 的伦理技能）

> 政策层（为什么）：`docs/AI-Ethics-Policy/`（三语） ｜ 实施层（做成什么）：`ethics/`
> 产品 AI 基于 QwenPaw，伦理以「**横向技能 + 工程字段 + 流程**」三处落地。

### 伦理技能中心 `ethics/`
- `ethics/实施清单.md` —— 七原则 → 工程产物 → 勾选（**主表，逐条对照**）
- `ethics/prompts/_ethics_base.md` —— 共享伦理基线（8 条硬规则），注入所有 QwenPaw Agent 前缀
- `ethics/qwenpaw-skills/` —— 4 个 QwenPaw 伦理 Agent：

  | 技能 | 职责 | 原则 | 初赛优先 |
  |------|------|------|----------|
  | `source-attribution` | 来源标签 + 置信度，低置信回退 | 透明度 | ⭐ |
  | `anti-sycophancy` | 反逢迎、不编史料、纠正错误假设 | 人类控制 | ⭐ |
  | `content-safety-review` | 高风险内容上线前审核 | 问责+安全 | 后做 |
  | `fairness-gate` | 输入特征白名单 + 跨语言一致性 | 公平性 | 后做 |

- `ethics/checks/` —— 本地伦理测试（test_fairness / test_transparency / 对抗纠正…）

### 一句话方法论
让每个 AI 输出都做到 **可标注来源 · 可解释理由 · 可被用户否决 · 可被审计追溯 · 可被删除**。

### 初赛最小伦理包（9 项，详见 `ethics/实施清单.md` §9）
来源标签 chip · AI 生成徽章 · 推荐理由 · 低置信回退"未能确定" · 跨语言一致性测试 · 审计日志+三类责任人 · 最小注册+授权开关 · 图片去 EXIF · 路线 `reviewed`+安全免责 · 反逢迎 Prompt。

### 伦理任务在各阶段的落点
- **Phase 1**：POI `source_type` 来源分级入库 ✓（已在清单）
- **Phase 3**：配 `source-attribution` + `anti-sycophancy`；讲解/路线响应加 `source_type`/`confidence`/`ai_generated`；注入伦理基线
- **Phase 4**：图片脱敏、授权开关+暂停定位、安全免责+官方入口、先问后播
- **Phase 5**：明信片不胁迫/可跳过、合影脱敏
- **Phase 6**：跑 `ethics/checks/`、完成初赛最小包、合规映射复核
