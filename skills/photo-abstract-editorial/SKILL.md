# 技能：摄影抽象编辑明信片（photo-abstract-editorial）

将一张用户授权的真实照片制作成一张完成的竖版编辑风旅行回忆图。成品由**原照片保留区 + 抽象记忆面板 + 原创英文标题**组成；这不是滤镜、照片重画、拼贴或单独的抽象画。

## 使用条件

- 仅在用户提供或明确授权使用的照片存在时使用；先调用 `view_image` 识别照片中的空间、色彩与主体关系。
- 将该照片作为唯一的内容来源。允许等比缩放或为构图做轻微裁切；不得重画、扩展、替换、修图或改变照片内容。
- 没有用户授权照片时，不得把纯文本生成图或网络图片说成用户照片。应转交 `qwen-image-postcard`：生成结果须标为“AI 场景示意”，工具失败须如实说明。

## 制作流程

1. 内部提取照片中三至六项决定性事实：主体关系、比例、方向、间距、层次、光线、色彩角色与留白。
2. 将未改变的照片放在成品上方或主区域；下方使用平整、连续的象牙白面板（推荐 `#F3F0E8`）。照片与面板直接衔接，不使用相框、胶带、阴影、撕纸边缘或样机效果。
3. 在面板中以少量抽象标记重构照片的关系，而非复制物体轮廓。使用一种主标记家族、至多两种辅助标记；颜色只能从照片提取，并降低饱和度。
4. 保留充足留白。标志性建筑最多保留一至三个身份线索；人物只能是连续、不规则的短竖形或轻微收分色块，不能出现人脸、肢体或服装细节。
5. 在面板内放置一个基于可见事实、两至五个词的原创英文标题，使用克制的编辑衬线字体。不得加入地点说明、日期、logo、水印、编号或其他文字。
6. 调用 `edit_image_qwen`，以本地照片绝对路径作为 `reference_images`，生成竖版成品。提示词应重复上述保真与极简抽象约束。

## 交付与失败处理

- 只向用户发送独立、干净的最终 PNG；不要发送参考图对比、拼接预览或编辑过程截图。
- 若工具返回“参考图 + 生成图”的拼接预览，只发送工具 `Saved to` 路径对应的最终成品。
- 调用失败、未配置 API Key 或没有可用授权照片时，必须如实说明，绝不伪装成已生成。
